# Springer Nature Elements — 公式参照元と利用上の注意

確認日: 2026-11-20。

| 領域 | 公式資料 |
| --- | --- |
| Elements導入（パッケージ・テーマ・Sass・コンポーネント） | https://eds.springernature.com/get-started/ |
| Nature向けカラーの考え方 | https://eds.springernature.com/foundations/nature/colour/ |
| Nature向けタイポグラフィ | https://eds.springernature.com/foundations/nature/typography/ |
| デザイントークン | https://eds.springernature.com/design-tokens/ |
| 旧公開Frontend Toolkits | https://github.com/springernature/frontend-toolkits |
| Nature論文図版の規定（別スキル） | https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/ |

公開された旧Frontend ToolkitsはMITだが、**新しいElements npmの各要素や素材全体について、旧リポジトリのMITだけで使用条件を断定しない。** 実際に導入するpackageのLICENSEを確認する。

- Natureの公式書体HardingやGraphik等の商用・専用フォントのファイルは同梱・共有しない。必要な書体は正規の利用権を確保。
- Nature/Springer Natureのロゴ・商標や公式Webデザインを無断コピー・再配布しない。
- このスキルのMarkdownとサンプルHTML/CSSは、参照した情報を元にassb-labが独自制作したもの。
- 公式Webコンポーネントの規則と、論文Figureの寸法・画像ファイル規則を混同しない。
