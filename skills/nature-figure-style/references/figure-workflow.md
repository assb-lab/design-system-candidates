# Nature Figure Style — 図版制作・学会投影への変換

## 原データからの制作

1. 元測定データと処理スクリプト、図に使った列と単位を記録。
2. 装置ごとのデータ処理（XPS C1s基準補正、XRD波長、EISのNyquist軸、SEMの校正スケール等）が妥当か確認。**ここに示す例はデータの存在や採否を意味しない**。
3. 先に最終印刷幅をmmで確定。axesの範囲とマルチパネルのラベル・余白を決める。
4. 線図、注記、スケールバー、パネルラベルは編集可能なベクターで組む。写真は元画素を保持し、画像を架空に高解像化して提出しない。
5. `assets/scientific.mplstyle` を `plt.style.context(...)` に読み込む。matplotlibの `pdf.fonttype=42` と `svg.fonttype=none` を確認する。
6. PDF/SVGの原本と投稿先指定の形式を出力。印刷サイズで文字を実際にレンダリングして検査。

## グラフの科学的整合性チェック

- 軸には物理量と単位を入れる。図中の値・凡例・注記が元ファイルと一致する。
- 不確かさの表記（SD/SE/CI等）、独立な試料数・繰り返し数、データ欠損を明示する。
- ナイキストプロットのRe(Z)・-Im(Z)の符号と縦横の縮尺、XRDの2θ（使用線源）、XPSの結合エネルギーなど、分野特有の誤解を避ける。
- マルチパネルでは色に加えて線種・マーカー・直接ラベルで系列を区別し、比較可能な軸範囲を意識する。
- 顕微鏡画像を不自然に編集・生成しない。全画像への一律処理、加工履歴、スケールバーの校正を維持する。

## 画像ファイル簡易検査

`python scripts/preflight.py path/to/Figure_1.png --width-mm 89 --kind photo`

TIFF/JPEG等はPillowがあれば読み取れる。PNGはPython標準ライブラリで検査可能。
画像の画素幅を、**渡した最終図幅**へ割り付けた場合の実効dpiを計算する。混合図での写真パネル単位の解像度は別途検査が必要。PDF/SVGの埋め込みラスタ、フォント、実際のページサイズはこのスクリプトでは保証しない。

## スライドに転用するとき

論文用の5–7ptの図中文字をそのまま投影しない。PPTXなら軸ラベル・注記を最低16–20pt程度から検討し、会場の投影距離で実際に確認する。

- 論文版は原図として保存し、プレゼン用は別ファイルを作る。5–8 ptなど論文制作の小さな文字を投影資料へ直接転写しない。
- 科学的な値・単位・論理は変えず、見出し・注記の縮尺と構図のみ再配置する。
- 元データ、matplotlibスクリプト、PDF原本、PPTXに埋めた図の出典を記録する。

## 遵守事項

このスキルは出版社の承認証明でも公式図版テンプレートでもない。TOC Graphic、Cover Art、Graphical Abstractは記事種別ごとに別扱い。投稿時の最終判断は公式投稿規定による。
