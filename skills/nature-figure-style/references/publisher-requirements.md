# Nature Figure Style — 公式規定の確認メモ

**最終確認日: 2026-11-20。** 以下は **Nature本誌のFigure Guide（Nature Portfolio全誌へ一括適用しない）** からの要点だけを独自に整理したもの。出版社グループ全体の一律規約ではない。作業着手時に対象誌・記事種別・初回提出か最終製版かを確認する。

## 判断の優先順位

1. 対象のJournal公式「Instructions for Authors」「Artwork/Figure Preparation」「TOC/Graphical Abstract」の現行版。
2. 該当する記事種別・段階（初稿、修正稿、受理後、最終製版）の要件。
3. このガイドに記載する出版社の代表例。
4. ここにあるmatplotlibスタイル／編集しやすい制作初期値。

**規則を無条件にコピーしない:** Nature本誌 ≠ Nature Portfolioの全誌、ACSのある誌 ≠ 全ACS誌、RSC Advances ≠ 全RSC誌、Wiley共通ガイド ≠ Advanced Materials等の固有規定。

## 補足

本誌図版は一般の図中文字5–7 pt、パネルラベルは8 ptの太字小文字。標準的なサンセリフ（Arial/Helvetica等）を使い、フォントをアウトライン化せず編集可能にする。

グラフの軸・目盛・単位を必ず表示し、余計なグリッド、影、装飾を避ける。印刷時は1段89 mm／2段183 mm、高さ最大170 mm。写真は最低300 dpi、450 dpiを高品質目標とし、線・文字はベクターで渡す。色はRGB推奨。

Natureの図版本体の規定とカバーデザイン・Research Briefing等の規定を混同しない。Graphical Abstractが必要かは対象誌・記事種別ごとに再確認する。

第三者図版・写真・化学構造・AI生成要素を含む場合は、対象誌の権利・AI利用規定を確認する。ソースと変更履歴を残す。
