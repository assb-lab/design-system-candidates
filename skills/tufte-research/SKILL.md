# Tufte Research

これは **assb-labが独自に記述したデザイン適用スキル** です。参考元の公式テンプレート、ソースコード、ロゴ、フォントファイルは含みません。

## 適した用途

- 研究手法の解説HTMLと技術ノート
- 講演配布資料・長文の研究紹介
- グラフ・タイムラインの丁寧な注釈

## デザイン思想

温かい紙の色、落ち着いたセリフ、本文の近くに配置した余白注釈、飾りを減らしたデータ可視化。

### 色と書体

| Role | HEX |
| --- | --- |
| `background` | `#FFFFF8` |
| `surface` | `#F8F6ED` |
| `text` | `#263137` |
| `muted` | `#5D686B` |
| `primary` | `#8A3F33` |
| `accent` | `#276C73` |
| `border` | `#D8D6C7` |
| `grid` | `#E3E3D7` |

- グラフ系列色（順序）: `#276C73` / `#B45537` / `#6E59A0` / `#748B40` / `#986A86`
- 欧文: Source Serif 4、和文: Noto Serif JP。代替フォントが必要な環境では文字組み・行送りを再確認する。
- デザイントークンの単一参照元は `assets/tokens.json` とし、Webなら `tokens.css`、Python図表なら `scientific.mplstyle` を使用する。
- 特定の大学・企業の公式ロゴ、ブランド、認証マークは自作せず、依頼者が正当に用意した素材を使う。

## スライド・レイアウト

1. 文書やHTMLでは本文2/3＋余白注釈1/3を基本として、狭幅では注釈を本文下へ移す。
2. 口頭発表では余白注釈を減らし、タイトル・図・結論の文字を投影サイズに拡大する。
3. 線の直接ラベルを優先し、離れた場所にある凡例を減らす。

- スライドは原則16:9。タイトル28–36pt、本文24–30ptを出発点とし、画像やグラフの占有率を優先する。密度を上げる場合でも投影で実際の可読性を確認する。
- スライドごとに結論が伝わる見出しを使い、出典と測定条件を残す。
- 会議・学会主催者・投稿先が指定するテンプレートがあれば、そのレイアウト・ロゴ・配色規則を優先する。

## 科学図・グラフ

- 意味のないグリッドや枠線を抑制し、単位と出典は残す。
- 論拠を補足する注釈は図のそばに置き、読み取りのための適切なコントラストを確保。

- 実験値を創作・補間・切り捨てたり、不都合な点を非表示にしたりしない。
- 軸名・単位・サンプル数・不確かさ（SD/SE/CI等）・対数/規格化・除外基準はデータに基づいて表現する。
- 色だけで系列を区別せず、線種・マーカー・ラベルも併用する。連続量には目的に応じた連続色尺度を使う。
- 顕微鏡画像は元画像の保存と適切なスケールバーを優先。科学的な意味を変える画像処理をしない。
- 論文用図版は投稿先の**現在の**図版要件を確認し、スライド用の文字サイズを混同しない。

## 出力媒体ごとの指針

- **PPTX:** PowerPointが必要なら編集可能なテキスト・図形・グラフを優先し、数値や図表が再編集可能な元ファイルも残す。
- **HTMLスライド:** `assets/slide-template.html` を構造の出発点にする。最終サイズ16:9で描画し、オーバーフローを検査する。
- **Webアプリ:** 長文の技術解説や静的Webに向く。実験操作画面にはCarbon Research等を優先する。 CSSカスタムプロパティを読み込み、既存UIのスタイルを無断で壊さない。
- **Matplotlib:** `plt.style.context("path/to/assets/scientific.mplstyle")` を使う。SVG/PDF書き出し時はフォント・透明度・ラベルの可読性を確認する。
- **ポスター/文書:** 元データを保持し、図中文字の最終物理サイズ・印刷条件を確認する。

## 作業フロー

1. 成果物の種類（PPTX/HTML/Webアプリ/論文図/ポスター）、閲覧条件、学会や投稿先の規定を確認する。情報が足りなければ明示的な仮定で進める。
2. `assets/tokens.json` から共通色と文字設定を使用し、見出し・本文・図表・注記の階層を決める。
3. 事実、測定値、画像、出典を元資料から埋め込み、図表のスケール・欠損・凡例を検証する。
4. スライドなら全ページをレンダリングして確認し、HTMLなら異なる画面幅で確認する。図表を読みやすいサイズで出力する。
5. 元ソース、編集可能な成果物、必要なエクスポート形式、使用した素材の出典を納品する。

## 同梱アセット

- `assets/tokens.json` — 色/書体のクロスメディア定義
- `assets/tokens.css` — Web向けのCSS変数
- `assets/scientific.mplstyle` — Matplotlib用スタイル
- `assets/slide-template.html` — 16:9 HTMLスライドの雛形（実データ未挿入）
